## 🌟 核心特色

- 🚀 **極致輕量 (< 8 MB)**：
  - 單一獨立靜態二進位檔案，零外部 DLL、零 Runtime 依賴，整體體積小於 8MB。
  - 內建靜態 Web 前端資源，雙擊即跑。
- 🖥️ **免裝客戶端 (Clientless)**：
  - 控制端只需現代瀏覽器（Chrome, Edge, Safari），開箱即用。
  - 採用 **WebCodecs + H.264** 硬體解碼，延遲低至 30~50ms，支援 30~60 FPS 流暢串流。
- ⚡ **雙擷取引擎 (DXGI + GDI)**：
  - 預設採用 **DirectX 11 DXGI Desktop Duplication** GPU 顯存直取，CPU 佔用率極低 (< 3%)。
  - 支援多螢幕熱切換，自動感知並校正硬體螢幕旋轉（如副螢幕倒置 180°）。
  - DXGI 不可用時自動無縫回退至 GDI 備援引擎。
- 🛡️ **三級權限安全架構**：
  - **等級 1：僅觀看 (View)** — 僅串流視訊，全面禁用鍵盤、滑鼠、剪貼簿與檔案上傳。
  - **等級 2：一般控制 (Standard)** — 完整支援鍵鼠控制、雙向剪貼簿與檔案傳輸，禁止破壞性特權組合鍵。
  - **等級 3：完全控制 (Admin)** — 解鎖所有特權功能與系統鍵（如工作管理員、Ctrl+Alt+Del）。
- 🔑 **雙軌驗證機制**：
  - **存取密碼驗證**：三組 6 位數獨立密碼，輸入不同密碼自動賦予對應角色權限。
  - **被控端即時審核**：控制端可發送連線請求，被控端桌面跳出原生視窗由主人一鍵決定核准權限或拒絕。
- 📋 **全功能雙向剪貼簿**：
  - 文字變動自動感知同步（無繁瑣剪貼簿按鈕，背景即時雙向鏡像）。
  - 支援遠端截圖貼上：在控制端按下截圖後於畫面直接 `Ctrl + V`，自動轉為點陣圖注入被控端剪貼簿。
- 📁 **大檔案拖曳傳送**：
  - 直接將檔案拖曳至瀏覽器畫面即可上傳，自動儲存至被控端桌面。
  - 具備即時百分比進度條、已傳送大小與傳輸速度（MB/s）顯示。
- 👥 **多人協同連線與智慧輸入鎖 (Multi-User Collaboration)**：
  - **在線成員面板**：即時顯示所有在線連線者與 IP，支援自訂個人暱稱與專屬色彩標籤。
  - **輸入租約鎖 (Lease Lock)**：同一時間由單一主控者操作，連續鍵鼠自動續約，避免多人輸入打架；支援管理員強制接管或隨時手動釋放。
  - **協同彩色雷射指示筆**：非主控者滑動滑鼠時向所有端廣播動態彩色雷射指針，溝通指示直觀流暢且不干擾操作。
- 📶 **秒級連線感知與急速復原機制**：
  - 同步將 H.264 影像訊框流入與應用層心跳納入存活判定。
  - 超過 1 秒未收到數據即時呈現「⚠️ 訊號微弱」呼吸光暈警告；超過 3 秒假死直接主動斬斷連線並啟動 150ms 急速自動重連，徹底告別瀏覽器 TCP 半開假死定格。
- 🖱️ **被控端實體輸入絕對最高優先權**：
  - 採用 Win32 底層鉤子精確區分物理硬體與軟體模擬輸入。
  - 當被控端本機動滑鼠或敲鍵盤時，立即強行壓制並丟棄遠端指令 1.5 秒，保障主人操作主導權。
- 🪟 **純 Win32 原生管理視窗 & 系統匣常駐**：
  - 徹底隱藏黑色 CLI 終端視窗，原生 Win32 輕量介面。
  - 支援 Windows 系統匣常駐圖示、右鍵功能選單（顯示視窗、複製網址、緊急中斷所有連線、完全退出）。
  - 點擊右上角「X」自動最小化常駐至系統匣，後端連線不中斷。

## 🛠️ 技術架構

| 層級 | 使用技術 |
| :--- | :--- |
| **後端語言** | Go (1.24+) + CGO (Win32 / DirectX API 輕量呼叫) |
| **視訊擷取** | DirectX 11 DXGI Desktop Duplication API / Win32 GDI |
| **視訊編碼** | 原生輕量級 H.264 訊框編碼器 (Baseline Profile) |
| **傳輸協議** | WebSocket 二進位串流 (訊框) + JSON (控制與事件指令) |
| **前端解碼** | HTML5 Canvas + WebCodecs API (`VideoDecoder`) |
| **桌面 GUI** | 純 Win32 API (`user32.dll`, `shell32.dll`)，零外部 GUI 函式庫 |

## 📦 建置與編譯

### 前置需求
- Windows 10 / 11 64-bit
- Go 1.22+
- MinGW-w64 (GCC 64-bit，用於編譯 CGO 與 windres 資源)

### 編譯步驟

1. **編譯 Windows 圖示資源**：
   ```cmd
   windres -F pe-x86-64 -i app.rc -o app_windows_amd64.syso
   ```

2. **靜態建置單一執行檔**：
   ```cmd
   go build -ldflags "-s -w -extldflags '-static'" -o NanoDesk.exe .
   ```

產出的 `NanoDesk.exe` 體積小於 **8 MB**，包含所有圖示與前端靜態資源，可直接發布分發。

## 🚀 快速開始

1. 雙擊運行 `NanoDesk.exe`。
2. 程式將自動最小化命令列並顯示原生管理視窗，同時在右下角系統匣常駐。
3. 在管理視窗中點擊「**📋 複製網址**」，將網址發送給控制端。
4. 控制端以 Chrome 或 Edge 開啟該網址，輸入對應權限密碼或點擊「發送連線請求」通過審核後即可開始操作！
