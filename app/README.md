# NanoDesk APP

## 主頁與設定

頂部固定保留「新增連線」分頁，提供對方 ID 輸入、本機 ID 複製和線上狀態。所有設定都從右上角齒輪進入 APP 內的單一設定分頁。設定頁分為一般、連線與伺服器、安全與授權、剪貼簿與檔案、關於。關閉未儲存的設定會詢問儲存、捨棄或取消。

伺服器網址格式為 `https://主機名稱:連接埠`，不含路徑、帳密或查詢字串。額外 CA 憑證可指定 PEM 檔路徑；協調服務與 TURN TLS 都會檢查憑證及主機名稱。預設自動直連優先，也可選擇強制中繼、僅 TLS 中繼以排查網路。

設定儲存成功會撤銷既有桌面授權並中斷連線；僅開啟、切換或關閉設定分頁不影響連線。

## 固定 ID

首次啟動產生 Ed25519 金鑰，由伺服器分配唯一十位 ID。後續以挑戰簽章取回相同 ID。金鑰與設定使用 DPAPI 加密，存於 `%LOCALAPPDATA%\NanoDesk\state.bin`。同一 Windows 使用者及電腦更新或移動 EXE 不會改變 ID。

不同使用者、重灌或身分遺失可能取得新 ID；更換伺服器也可能取得不同 ID。損壞或無法解密的狀態會顯示錯誤，不自動覆寫。程式以使用者 SID 的全域 mutex 防止重複開啟，伺服器也會拒絕重複身分上線。請勿複製身分資料到其他電腦。

## 授權與遠端視窗

雙方使用相同 EXE，可同時接受連入與控制其他電腦。每個對外連線有獨立分頁。可拖曳排序、拖出主視窗成為獨立視窗，或拖回頂部分頁列。也可從獨立視窗選單選擇「移回主視窗」。移動分頁會保留原連線。輸入 ID 後，在加密通道內選擇人工核准或密碼登入，授權成功前不傳送桌面畫面。

無人值守預設關閉，啟用時至少設定一種角色密碼；空白停用該角色密碼登入。三角色為僅觀看、一般控制、完全控制，權限沿用 Web 版。這些是應用程式權限，並非 Windows 權限隔離。

連入授權成功後，獨立的被控小窗會按來源裝置分頁顯示角色與主控權。每頁可傳送對話及結束該連線。對外連線則可從遠端畫面的「對話」按鈕開啟聊天。訊息保存在該次工作階段的記憶體中。

圖示工具列在滑鼠停留約 500 毫秒後顯示提示；複合功能點擊開啟選單。每個螢幕有獨立編號圖示，選中者高亮，提示包含解析度及主要螢幕；數量多時可橫向捲動。切換螢幕依主控權判斷，會同步影響同一被控端的觀看者。

畫面使用 Media Foundation H.264 解碼與 Direct3D 11 顯示；Direct3D 失效時嘗試重建，並提供 GDI 顯示備援。解碼壅塞會丟棄相依 GOP、要求關鍵幀恢復；心跳不會掩蓋畫面停滯。

只有目前操作中的遠端視窗且持有主控權時，才自動同步文字／PNG 剪貼簿。失焦或中斷會釋放按鍵。指示筆可用於協同觀看。

## 檔案

從檔案圖示選取傳送，儲存至被控端實際桌面。同名加序號，不覆寫。每批最多 100 個檔案，總內容上限預設 1 GiB，可於被控端設定。APP 上限以內容總和計算，Web 上限另包含 HTTP multipart 封裝。

使用獨立可靠通道、小區塊串流與約 1 MiB/s 節流，保留操作流量空間。進度區分傳送與主機儲存；僅觀看不能傳送。最多同時寫入四個檔案；30 秒無進度、取消、斷線或撤權會清理未完成檔案，已提交的檔案保留。取消入口位於檔案圖示選單。

## 首版限制

Windows 10／11 x64，單一使用者互動桌面；不含音訊、錄影、任意檔案瀏覽、開機服務、登入畫面、UAC 安全桌面或真正 Ctrl+Alt+Del。Web 與 APP 不互通。中繼需正確部署伺服器及防火牆；不保證穿過所有企業網路政策。

完整 APP 目前超過 8 MB 目標，正式體積見根目錄 `BUILD-SIZES.txt`。跨實體電腦、混合 DPI、多螢幕熱插拔與長時間使用仍需依 [驗證紀錄](../TESTING.md) 驗收。
